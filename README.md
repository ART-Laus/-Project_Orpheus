# Project Orpheus

Личная музыкальная библиотека, полностью независимая от стриминговых сервисов.

- **Формат хранения**: AAC LC 256 kbps (FLAC — только для особо важных релизов)
- **Принцип**: один файл = одна композиция; плейлисты — ссылки, не копии
- **Канон**: альбомная версия трека; исключения — вручную
- **Обложки**: встроенные в файл, ≥ 1000×1000
- **Этап**: 1 из 6 (см. `ROADMAP.md`)

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt        # или: pip install -e .[dev]
cp .env.example .env                   # вписать SPOTIFY_CLIENT_ID / SECRET
```

Ключи Spotify: https://developer.spotify.com/dashboard → создать приложение.

## Использование

```bash
orpheus import                # импорт лайков + плейлистов из Spotify (нужен доступ к API)
orpheus import-csv exports/   # импорт выгрузок Exportify (CSV) из каталога
orpheus status                # сводка по статусам треков
orpheus stats                 # статистика и контроль качества базы
orpheus stats --duplicates    # списки дублей (по ISRC и по имени)
orpheus dedup                 # анализ дубликатов + отчёт data/reports/duplicates.md
orpheus dedup apply           # перелинковка плейлистов и удаление неканонических версий
```

### Дедупликация

`orpheus dedup` группирует дубли по двум уровням:
- **точные** (одинаковый ISRC — одна запись в разных релизах): автоматический канон по
  эвристике (лайк → не-сингл → ранняя дата), можно переопределить;
- **кандидаты** (имя + исполнитель совпадают, ISRC разный — ремастеры/каверы/демо):
  решение только вручную.

Ручные решения записываются в `data/decisions.json` (переживает повторные импорты):

```json
{
  "<ISRC>": {"canonical": "<track_id>", "reason": "альбомная версия"},
  "имя|исполнитель": {"skip": true, "reason": "это разные записи"}
}
```

`orpheus dedup apply` перелинковывает ссылки плейлистов на канонический трек,
жёстко удаляет неканонические записи и делает снапшот удалённого
в `data/backups/dedup-<дата>.json`.

Импорт через API сохраняется после каждой страницы: прерывание не теряет
прогресс, повторный запуск продолжает с места остановки.

### Импорт через Exportify (без доступа к API)

Если API Spotify геоблокирован, используйте браузерный экспорт:

1. Откройте https://exportify.app (с включённым VPN в браузере).
2. Войдите в Spotify, нажмите **Get Started** → отметьте все плейлисты и **Liked Songs**.
3. Скачанные CSVs положите в каталог (например, `data/exports/`).
4. `orpheus import-csv data/exports/`

CSV-импорт идемпотентен: повторный запуск заменяет плейлисты свежими снимками,
треки не дублируются. Жанры исполнителей в CSV отсутствуют — добираются позже.
